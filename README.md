# 🛒 E-Commerce Order Management System

A full-stack E-Commerce Order Management System that allows users to browse products, manage their shopping cart, place orders, and view order history.

The project consists of a FastAPI backend and a responsive HTML, CSS, and JavaScript frontend.

---

## 🚀 Features

- User registration and login
- JWT-based authentication
- Product management
- Product details page
- Product images
- Shopping cart management
- Add products to cart
- Place orders
- View order history
- Stock management
- RESTful API
- Responsive and animated user interface
- SQLite database integration
- Swagger API documentation

---

## 🛠️ Technologies Used

### Backend
